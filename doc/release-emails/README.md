# Archive des mails de release

Chaque fichier ici est le texte d'un mail envoyé aux utilisateurs / clients
OpenSankey, OpenSankey+ et SankeySuite. Convention de nommage :

```
YYYY-MM-DD-<produit>.md
```

`<produit>` = `opensankey`, `sankeysuite`, etc. La date est celle de l'envoi.

Le contenu source de vérité utilisateur reste :

- `client/public/WHATSNEW.md` : panneau « Nouveautés » de la modale d'accueil
  (rendu dans l'app, donc rédigé pour utilisateur final, FR + EN)
- `CHANGELOG.md` (racine + par submodule) : détail technique par version

Les mails archivés ici sont des extractions / synthèses thématiques, pas un
journal canonique.
