Style
=====

Modifier l'apparence d'un diagramme : forme et libellés des nœuds,
couleurs des flux, et réutilisation via les styles. Chaque page suit la
même structure (Résumé / Accès / Options / Voir aussi).

Le principe général : chaque nœud et chaque flux possède un **style**
qui décrit son apparence par défaut. Dans le menu de configuration,
modifier un attribut **surcharge** le style pour cet objet précis (la
valeur ne provient plus du style mais de l'objet lui-même). On peut
donc travailler à deux niveaux : éditer le style (effet global) ou
surcharger objet par objet (effet local).
