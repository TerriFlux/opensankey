Ordre d'affichage des éléments
==============================

Résumé
------

Quand des éléments se chevauchent (nœuds, flux, zones de texte,
images), l'**ordre d'affichage** détermine lequel passe au-dessus.
On le règle pour faire ressortir un élément, masquer une jonction
disgracieuse, ou poser un libellé par-dessus le reste.

Accès
-----

Barre de navigation **Graphe > Ordre d'affichage**.

Utilisation
-----------

- L'outil liste les éléments et permet de les remonter / descendre
  dans la pile de rendu (le dernier dessiné est au premier plan).
- Pour les flux uniquement, l'onglet **Édition des flux** offre aussi
  un déplacement rapide **par-dessus / par-dessous** les autres flux.
