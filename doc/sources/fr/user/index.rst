Documentation utilisateur
=========================

Bienvenue. SankeyApplication est un éditeur de diagrammes Sankey
orienté analyse de flux. Cette documentation est organisée pour
servir aussi bien le débutant qui découvre l'outil que l'analyste
qui cherche une fonctionnalité précise.

Par où commencer
----------------

**Je découvre l'outil**
   Suivre :doc:`tutoriels/premier_diagramme` (10 minutes), puis
   parcourir :doc:`concepts/index` pour comprendre le vocabulaire.

**J'ai un fichier Excel à exploiter**
   Aller directement à :doc:`tutoriels/depuis_excel` (15 minutes).

**Je veux faire de l'analyse de flux de matière (MFA)**
   Aller directement à :doc:`tutoriels/premiere_mfa` (20 minutes).

**Je cherche comment faire X**
   Consulter :doc:`guides/index` — les guides sont organisés par
   tâche (données, style, présentation, organisation, export, Excel,
   MFA, compte/licences).
